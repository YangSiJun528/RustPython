# 문자열 인터닝은 같은 불변 객체를 공유하게 한다

문자열 인터닝은 내용이 같은 여러 `PyUnicodeObject` 대신 대표 객체 하나를
사용하는 최적화다. 식별자와 속성 이름처럼 반복되는 문자열을 공유하면 저장 공간을
줄이고, CPython 내부에서 이미 인터닝된 문자열끼리 비교할 때 빠른 경로를 쓸 수
있다. 객체의 일반적인 참조 횟수 규칙이나 문자열의 값 비교 규칙을 바꾸지는 않는다.

```text
전: a ─→ "name" A     후: a ─┐
    b ─→ "name" B             ├─→ 대표 "name"
                              b ─┘
```

## 공유 범위와 수명은 문자열 종류와 빌드에 따라 다르다

CPython이 미리 준비한 한 글자 Latin-1 문자열과 `_Py_ID`, `_Py_STR` 문자열은 정적
singleton이다. 실행 중 동적으로 인터닝한 문자열은 인터프리터별 딕셔너리에 들어간다.
GIL 빌드에서는 동적 문자열이 mortal 또는 immortal일 수 있지만, 자유 스레딩 빌드의
인터닝 문자열은 항상 immortal이다.

인터닝 여부와 객체 수명 상태는 구현 세부다. 일반 Python 코드에서는 문자열 값이
같은지 `==`로 비교해야 한다. 우연히 같은 객체인지 검사하는 `is`는 값 비교를
대체하지 못한다.

상태값과 내부 API의 참조 계약은
[런타임 객체 참고 자료](../reference/runtime-objects.ko.md#문자열-인터닝-조회표)에 정리되어
있다. 바인딩과 일반 객체 수명은 [바인딩, 변경, 객체 수명](objects-and-lifetimes.ko.md)에서
설명한다.
