# CPython 내부 구현 학습 가이드

기존 `cpython-internals-notes/`를 독자가 읽는 순서와 목적에 맞춰 재구성한
문서 모음이다. 원문 대응 번역과 상세 구현은 기존 폴더에 그대로 두고, 여기서는
하나의 실행 흐름을 따라가는 입문 글과 주제별 설명, 작업 절차, 참조 자료를
분리해 제공한다.

## 버전별 가이드

- [CPython 3.14 내부를 실행 흐름으로 읽기](3.14/README.ko.md)
- [기존 상세 노트와 원문 대응 번역](../cpython-internals-notes/README.md)

내부 구조와 바이트코드는 CPython 버전마다 달라질 수 있다. 다른 버전에 내용을
적용할 때는 해당 버전의 소스와 `InternalDocs`를 다시 확인해야 한다.
