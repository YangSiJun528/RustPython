If you’re looking to embed RustPython into your application,
you’re likely looking for the <a href="https://docs.rs/rustpython-vm/0.6.0/x86_64-unknown-linux-gnu/rustpython_vm/index.html" title="mod rustpython_vm"><code>rustpython_vm</code></a> crate.</p>
<p>You can install <code>rustpython</code> with <code>cargo install rustpython</code>. If you’d like to inject your
own native modules, you can make a binary crate that depends on the <code>rustpython</code> crate (and
probably <a href="https://docs.rs/rustpython-vm/0.6.0/x86_64-unknown-linux-gnu/rustpython_vm/index.html" title="mod rustpython_vm"><code>rustpython_vm</code></a>, too), and make a <code>main.rs</code> that looks like:</p>

<div class="example-wrap"><pre class="rust rust-example-rendered"><code><span class="kw">use </span>rustpython::{InterpreterBuilder, InterpreterBuilderExt};
<span class="kw">use </span>rustpython_vm::{pymodule, py_freeze};

<span class="kw">fn </span>main() -&gt; std::process::ExitCode {
    <span class="kw">let </span>builder = InterpreterBuilder::new().init_stdlib();
    <span class="comment">// Add a native module using builder.ctx
    </span><span class="kw">let </span>my_mod_def = my_mod::module_def(<span class="kw-2">&amp;</span>builder.ctx);
    <span class="kw">let </span>builder = builder
        .add_native_module(my_mod_def)
        <span class="comment">// Add a frozen module
        </span>.add_frozen_modules(<span class="macro">py_freeze!</span>(source = <span class="string">"def foo(): pass"</span>, module_name = <span class="string">"other_thing"</span>));

    rustpython::run(builder)
}

<span class="attr">#[pymodule]
</span><span class="kw">mod </span>my_mod {
    <span class="kw">use </span>rustpython_vm::builtins::PyStrRef;

    <span class="attr">#[pyfunction]
    </span><span class="kw">fn </span>do_thing(x: i32) -&gt; i32 {
        x + <span class="number">1
    </span>}

    <span class="attr">#[pyfunction]
    </span><span class="kw">fn </span>other_thing(s: PyStrRef) -&gt; (String, usize) {
        <span class="kw">let </span>new_string = <span class="macro">format!</span>(<span class="string">"hello from rust, {}!"</span>, s);
        <span class="kw">let </span>prev_len = s.byte_len();
        (new_string, prev_len)
    }
}</code></pre></div>
<p>The binary will have all the standard arguments of a python interpreter (including a REPL!) but
it will have your modules loaded into the vm.</p>
<p>See <a href="../rustpython_derive/index.html"><code>rustpython_derive</code></a> crate for documentation on macros used in the example above.</p>
