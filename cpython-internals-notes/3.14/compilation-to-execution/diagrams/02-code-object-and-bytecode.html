바이트코드는 CodeObject의 표를 참조한다

예제 함수 calculate(price, quantity) · CPython 3.14.6
명령의 숫자 인자는 실제 값이 아니라 co_varnames나 co_names의 인덱스인 경우가 많다.
1. Python 소스
def calculate(
    price,
    quantity,
):
    subtotal =
        price * quantity
    return
        subtotal + BONUS
2. 함수 바이트코드
RESUME 0함수 실행 시작
LOAD_FAST_BORROW_LOAD_FAST_BORROW 1price, quantity 적재
BINARY_OP 5 (*)두 값 곱하기
STORE_FAST 2subtotal에 저장
LOAD_FAST_BORROW 2subtotal 적재
LOAD_GLOBAL 0BONUS 조회
BINARY_OP 0 (+)두 값 더하기
RETURN_VALUE1015 반환

→
co_varnames[2] = 'subtotal'

CodeObject에는 현재 값이 없다. BONUS == 1000과 subtotal == 15 같은 값은 실행 중 프레임과 네임스페이스에서 얻는다.
