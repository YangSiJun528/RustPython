Frame의 슬롯과 평가 스택에는 객체 참조가 들어간다

CPython의 개념적 PyObject 모델 · 이름은 값을 담는 상자가 아니라 객체를 가리키는 바인딩이다
지역 슬롯 0 = 5는 간단히 쓴 표현이다. 실제 의미는 지역 슬롯 0 → 정수 객체 5에 가깝다.

Frame은 실제 값을 복사해 넣기보다 객체 참조를 보관한다

CPython 3.14의 내부 스택 표현은 _PyStackRef지만, 여기서는 객체 참조로 단순화한다.

실제 객체는 각각 따로 존재

대입은 바인딩을 바꾸고, 메서드는 같은 객체를 변경할 수 있다

1. 같은 객체를 함께 가리킴

x = [1, 2]
y = x
x와 y는 같은 리스트 객체를 가리킨다. 새 리스트 복사는 일어나지 않는다.

2. 객체 자체를 변경

y.append(3)
같은 리스트 객체가 바뀌므로 x와 y 모두 [1, 2, 3]을 본다.

3. 이름만 새 객체로 재바인딩

y = [9]
y만 새 리스트를 가리킨다. x는 기존 [1, 2, 3]을 계속 가리킨다.
수명 관리: 일반적인 mortal 객체는 마지막 강한 참조가 없어지면 참조 계수 방식으로 회수될 수 있다. 참조 계수만으로 회수되지 않는 도달 불가능한 순환은 cyclic GC가 보완한다. BORROW와 immortal 객체 같은 최적화가 있으므로 화살표 수를 실제 참조 계수로 읽으면 안 된다.
